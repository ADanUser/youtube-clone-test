# Материалы ИИ

В `conversations/` хранятся только исходные экспорты тех диалогов Codex, которые
использовались при работе над этим проектом. Личные и несвязанные с проектом
сессии в репозиторий не добавляются.

## Формат и экспорт

Формат — Markdown, созданный штатной командой Codex `/export`, без ручного
редактирования, пересказа или замены скриншотами. Для каждой проектной
сессии:

1. Дождитесь завершения текущего хода Codex.
2. Откройте нужную сессию через `/resume` и убедитесь, что её рабочая папка —
   этот репозиторий.
3. Выполните `/export ai/conversations/YYYY-MM-DD-short-name.md` из корня
   репозитория. Имя описывает тему, но не заменяет содержимое.
4. До добавления в Git проверьте файл на пароли, access key, cookie, токены и
   другие секреты. Если секрет есть, не коммитьте экспорт и согласуйте
   безопасную передачу. Не редактируйте исходник молча.

Этот способ проверен для установленного `codex-cli 0.162.0-alpha.17.2` и соответствует
[официальной команде `/export`](https://learn.chatgpt.com/docs/developer-commands#export-a-conversation-with-export).

## Фактическая обвязка

- Проектные правила: `AGENTS.md`.
- Архитектура и план: `ARCHITECTURE.md`, `TODO.md`.
- Настройки проекта: `pyproject.toml`, `.env.example`, `compose.yaml` и файлы
  `tests/compose/`. Безопасный снимок персональных настроек Codex хранится в
  [`environment.md`](environment.md); auth/state-файлы и локальные пути не копируются.
- Системный skill `openai-docs` использовался для проверки Codex/AGENTS.md и
  формата экспорта; снимок его инструкции лежит в `skills/openai-docs/SKILL.md`.
- В сессиях 04 и 06 вызывалась UI-обвязка `unified-computer-use`/`cua_repl` для
  попытки визуальной проверки. Внешние аккаунты и проектные MCP-серверы не
  подключались.

Папка считается готовой только после того, как все реально использованные проектные
диалоги экспортированы, проверены и добавлены в Git.
